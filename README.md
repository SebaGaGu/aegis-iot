# AEGIS — Maleta Inteligente

## Equipo 3 — Proyecto IoT

### Descripción
AEGIS es un sistema inteligente de vigilancia de equipaje basado en Internet de las Cosas (IoT).

Su objetivo es proporcionar mayor seguridad y tranquilidad a los viajeros, permitiéndoles conocer si su maleta ha sido abierta o ha sufrido golpes mientras no podían supervisarla.

### Funcionalidades previstas
- Detectar aperturas mediante un sensor de luz.
- Detectar golpes utilizando un acelerómetro.
- Activar y desactivar la vigilancia desde una aplicación móvil.
- Consultar el estado de la maleta.
- Recibir avisos cuando se detecten eventos.
- Acceder a la aplicación mediante una pantalla de inicio de sesión.
- Consultar información del proyecto en la sección «Acerca de».

### Tecnologías
- M5Stack como plataforma de prototipado.
- Sensor de luz.
- Acelerómetro.
- Aplicación móvil.
- Comunicación entre el prototipo y la aplicación (por definir).

### Organización
El proyecto se desarrolla por el Equipo 3 para la asignatura de IoT.
